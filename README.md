# دروس اللغة العربية لغير الناطقين بها — الإمام أحمد شيخ توري
# Arabic Lessons for Non-Native Speakers — Imam Ahmad Sheikh Touri

موقع/تطبيق تفاعلي لتعلّم العربية الفصحى المبسّطة من خلال **المحادثات والمواقف اليومية**،
مع **ترجمة إنجليزية** و**نُطق صوتي** و**اختبارات تفاعلية**.

An interactive web app for learning simplified Modern Standard Arabic through
**everyday conversations**, with **English translation**, **audio**, and **interactive quizzes**.

> 🔗 **الموقع المنشور مباشرة:** <https://sheikhtouray13-crypto.github.io/sheikh-touri-arabic/>

---

## ✨ المميزات | Features

- 💬 **8 دروس حوارية** في مواقف يومية (التحيات، المطار، السوق، المطعم، الطبيب، البنك، الطريق، الفندق).
- 🌐 **تبديل فوري للواجهة** بين العربية والإنجليزية (زر `English` / `العربية`).
- 🔤 **ترجمة إنجليزية + نقل صوتي (transliteration)** لكل جملة، مع إمكانية إظهارها/إخفائها.
- 🔊 **نُطق صوتي بالعربية** لكل جملة وكل كلمة (يعمل عبر Web Speech API في المتصفح).
- 📝 **اختبارات تفاعلية** بعدد أسئلة لكل درس مع نتيجة فورية وشريط تقدّم.
- 📈 **حفظ التقدّم تلقائياً** في المتصفح (localStorage).
- 🌙 **الوضع الليلي/النهاري** و**تصميم متجاوب** مع الجوال.
- 🔎 **بحث وتصفية الدروس** حسب المستوى.

## 🚀 طريقة التشغيل | How to run

الموقع يعمل مباشرة بدون أي تثبيت:

1. افتح الملف `index.html` بالنقر المزدوج عليه في المتصفح
   (الأفضل: Chrome أو Edge للحصول على النُطق الصوتي).
2. ابدأ الدرس الأول ثم تنقّل بين الدروس من الصفحة الرئيسية.

> ملاحظة: للحصول على النُطق الصوتي بالعربية يُفضَّل استخدام متصفح Chrome أو Edge.
> إذا لم تسمع صوتاً، تأكد من توفّر صوت عربي في نظام التشغيل.

### تشغيله كموقع عبر خادم محلي (اختياري)
إن رغبت في نشره على الإنترنت، ارفع محتويات المجلد كما هي (ملف `index.html` والمجلد `assets`)
على أي استضافة ثابتة مثل **GitHub Pages** أو **Netlify** أو **Vercel** — ولا يحتاج أي إعداد.

## ➕ كيف تضيف درساً جديداً؟ | Adding a new lesson

افتح `assets/js/lessons.js` وأضف عنصراً جديداً إلى المصفوفة `LESSONS` بنفس الشكل:

```js
{
  id: "my-lesson",                     // معرّف فريد بالإنجليزية (بدون مسافات)
  icon: "☕",
  level: "A1",                          // A1 / A2 / B1 ...
  accent: "#0ea5e9",                    // لون بطاقة الدرس
  title:   { ar: "في المقهى", en: "At the Café" },
  summary: { ar: "وصف قصير", en: "Short description" },
  dialogue: [
    { sp: { ar: "أحمد", en: "Ahmed" }, ar: "الجملة بالعربية", en: "English", tr: "transliteration" }
  ],
  vocab: [
    { ar: "كلمة", en: "word", tr: "kalima" }
  ],
  quiz: [
    { q: { ar: "السؤال؟", en: "Question?" },
      options: [ { ar: "خيار", en: "option" }, { ar: "خيار", en: "option" } ],
      answer: 0 }
  ]
}
```

سيظهر الدرس تلقائياً في الصفحة الرئيسية، وتُحسب نتيجته ويُحفظ تقدّمه بدون أي تعديل آخر.

## 🎨 الألوان | Color theme

اللوحة المستخدمة: **أزرق ملكي + ذهبي**.

| اللون | الاستخدام |
|---|---|
| `#1e3a8a` / `#2563eb` | اللون الأساسي (أزرق ملكي / Royal blue) |
| `#60a5fa` | لون مميز ثانوي (أزرق فاتح) |
| `#c69a2d` / `#f4cd63` | اللون الذهبي للتمييز والجوائز |

كل الألوان معرّفة كمتغيّرات CSS في `:root` داخل `styles.css`، ويمكن تغييرها من مكان واحد.
